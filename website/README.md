# Spoke website

This is a dependency-free static site for GitHub Pages.

Preview it from the Spoke repository root:

```sh
python3 -m http.server 4174 --directory website
```

Then open <http://127.0.0.1:4174>. The Pages workflow deploys these files as-is.

Keep product claims aligned with the root `README.md` and `docs/CONTEXT.md`.
Spoke owns social concepts; Jolt owns the application-agnostic protocol.
